## PCA 投影與重建：確認無誤

固定點雲：

```python
points = [(-3,-1),(-2.5,-1.6),(-2,-.6),(-1.5,-1.2),(-1,-.2),(-.5,-.8),
          (.5,.8),(1,.2),(1.5,1.2),(2,.6),(2.5,1.6),(3,1)]
```

成對互為相反數，所以平均恰為零。獨立使用 `numpy.cov(points, rowvar=False)` 與 `numpy.linalg.eigh` 得到樣本共變異數與特徵值：

```text
C = [[4.136363636363637, 1.9272727272727272],
     [1.9272727272727272, 1.0981818181818181]]
eigenvalues = [0.16329282609751583, 5.0712526284479384]
principal direction angle = 25.877277300212153 degrees
```

程式角度公式 `atan2(2*Cxy, Cxx-Cyy)/2` 對應最大特徵值方向。取單位向量 u，投影 z_i=x_i^T u、重建 xhat_i=z_i u：

```text
sample projected variance = sum(z_i^2)/(n-1) = 5.0712526284479384
mean squared reconstruction distance = sum(||x_i-xhat_i||^2)/n = 0.14968509058938947
(11/12)*variance + MSE = 4.798333333333333
sum(||x_i||^2)/12 = 4.798333333333333
```

兩個指標各用 n-1 與 n，正文已明確說不能直接相加。對固定資料，最大化投影平方和等於最小化正交殘差平方和；固定分母不改變最佳方向。u 換成 -u 時，z 變號，重建不變。

## 低秩例題：確認無誤

令 q 為 `np.linspace(-1,1,48)`。矩陣可獨立展開為：

```python
A2 = np.outer(np.exp(-5*q*q), np.exp(-5*q*q))
A2 += .2*np.outer(np.cos(3*q), np.cos(6*q))
A2 -= .2*np.outer(np.sin(3*q), np.sin(6*q))
```

這使用 cos(a+b)=cos(a)cos(b)-sin(a)sin(b)，共三個秩一矩陣，因此秩至多三。與教材 meshgrid 公式比對：

```text
max(abs(A-A2)) = 2.220446049250313e-16
numerical rank = 3
first singular values = [14.141950820778305, 4.9214269598844265,
                         3.1543914646678504, 1.3595085938811966e-15,
                         8.11427047719704e-16]
```

參考程式正確以 `(u[:,:k]*s[:k]) @ vt[:k]` 重建，並核對殘差平方和與尾端奇異值平方和、誤差不增加、全分解可還原。k=4 接近完整重建只適用這個特殊例子；正文已限制此結論。

## 梯度下降例題：確認無誤

對 f(x)=(x-3)^2，更新式推出 e_(t+1)=(1-2η)e_t，其中 e_t=x_t-3。三個倍率分別為 0.8、-0.6、-1.2，對應單側收斂、振盪收斂與振盪發散。

獨立從 x0=0 迭代 30 次：

| η | x30 | f(x30) |
|---|---:|---:|
| 0.1 | 2.996286179882144 | 1.3792459867793054e-05 |
| 0.8 | 2.9999993367782407 | 4.3986310199500144e-13 |
| 1.1 | -709.1289413993122 | 507127.62917850504 |

參考程式逐步和解析式核對；有限差分也檢查指定位置與步長。這是固定二次函數的驗證，不建立任意損失函數的收斂保證。

## 最短路徑例題：確認無誤

不使用 NetworkX，直接列舉 B、C、D 的不重複排列，兩端接 A 與 E，只保留相鄰點都有邊的序列，得到全部七條簡單路徑：

| 路徑 | 長度 |
|---|---:|
| A-B-C-D-E | 5 |
| A-B-D-E | 7 |
| A-C-D-E | 7 |
| A-B-C-E | 8 |
| A-C-E | 10 |
| A-C-B-D-E | 11 |
| A-B-D-C-E | 12 |

所有邊長為正，含循環的路線不會比去掉循環後更短；列舉簡單路徑足以確認全域最短值。A-B-C-D-E 是唯一最短路徑。參考程式另對孤立點 F 捕捉 `NetworkXNoPath`，未將無路徑當成距離零。
