# 訂單資料 PCA 降維

資料：`data/orders.csv`，800 筆、11 個數值特徵。先標準化後做 PCA。

解釋變異比例（%）：

| PC | 個別 | 累積 |
|---|---:|---:|
| 1 | 31.96 | 31.96 |
| 2 | 20.50 | 52.46 |
| 3 | 16.55 | 69.00 |
| 4 | 14.86 | 83.87 |
| 5 | 9.07 | 92.94 |
| 6 | 3.33 | 96.26 |

結論：保留 5 個主成分可解釋 92.94% 變異；若追求更精簡，4 個可達 83.87%。PC5 主要對應 `rider_odometer_m`，具獨立訊號，建議保留。
