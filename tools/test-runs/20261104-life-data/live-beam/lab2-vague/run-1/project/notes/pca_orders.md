# orders.csv PCA 降維

- 原始 11 個特徵、800 筆訂單，先標準化再做 PCA。
- 解釋變異：PC1 32.0%、PC2 20.5%、PC3 16.6%、PC4 14.9%、PC5 9.1%。
- 累積：4 個主成分 83.9%，5 個主成分 92.9%。
- Kaiser / 平行分析：特徵值 > 1（或 > 隨機）的只有前 4 個（3.52, 2.26, 1.82, 1.64）；第 5 個特徵值 ≈ 0.999，幾乎只代表 `rider_odometer_m`。
- 建議：以 90% 變異為門檻取 **5 個主成分**；若用 Kaiser/平行分析則取 **4 個**。降維結果存於 `data/orders_pca5.csv`，scree plot 見 `figs/pca_scree.png`。
