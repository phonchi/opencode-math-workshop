1. **數學正確性**：公式與演算法步驟是否正確？矩陣維度是否對得起來？
2. **可重現性**：所有用到隨機性的地方是否都有固定種子（`random_state=0`
   或 `np.random.seed(0)`）？

   sklearn 的對應函式來充數。
4. **數值穩定性**：有沒有除以可能為零的量？有沒有對可能為負的數開根號？
   大數相減造成的抵消誤差？
