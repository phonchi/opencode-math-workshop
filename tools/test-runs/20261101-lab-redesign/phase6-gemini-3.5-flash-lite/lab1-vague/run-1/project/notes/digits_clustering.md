# Scikit-learn Digits 資料集分群分析筆記

## 1. 資料集概述
`sklearn.datasets.load_digits` 包含 1,797 筆 $8 \times 8$ 像素的手寫數字影像（維度 $d = 64$），其真實標籤（Ground Truth）共有 10 類（數字 $0$ 至 $9$）。

## 2. 評估指標與方法
我們使用以下指標評估 $k$ 從 $2$ 到 $15$ 的分群表現：
- **內部驗證指標（Unsupervised）**：
  - 輪廓係數（Silhouette Score）：衡量群內緊密度與群間分離度，數值越高越好。
  - Calinski-Harasz Index：群間變異與群內變異的比值，數值越高越好。
  - Davies-Bouldin Index：群內距離與群間距離的相似度，數值越低越好。
- **外部驗證指標（Supervised Comparison，對應真實標籤 $y$）**：
  - 調整蘭德指數（Adjusted Rand Index, ARI）：衡量分群結果與真實標籤的一致性。
  - 標準化互資訊（Normalized Mutual Information, NMI）。

## 3. 實驗結果與分析

### (1) 最佳群數選擇
- **語義與業務邏輯上的最佳群數：$k = 10$**
  - 理由：資料集本身即為 $0$ 至 $9$ 共 10 種手寫數字類別。從監督式分類與領域知識來看，$k = 10$ 是最符合實際意義的群數。此時 ARI 高達 $0.6669$，NMI 達到 $0.7394$，顯示非監督式的 K-Means 分群能相當好地還原出原本的數字類別。
- **內部指標（Silhouette Score / Davies-Bouldin）的最佳群數：$k = 9$**
  - 理由：在純幾何距離與空間分佈上，$k = 9$ 的 Silhouette Score 達到最高（$0.1891$），Davies-Bouldin 指數最低。這主因是某些形狀高度相似的數字（例如數字 $1$ 與 $7$、或 $0$ 與 $6$）在 64 維空間中幾何邊界重疊度高，演算法會將其合併或調整以優化幾何分離度。
- **外部指標（ARI）的最佳群數：$k = 11$**
  - 理由：當 $k = 11$ 時，ARI 達到最大值 $0.7264$。這是因為某些字體變異較大（例如數字 $1$ 或 $4$ 有不同的書寫風格）的類別被拆分成兩個子群，反而與真實標籤對齊得更好。

## 4. 結論建議
若以**業務或識別任務的物理意義**來看，**建議分為 10 群 ($k = 10$)**；若純粹追求幾何緊密性，則 $k = 9$ 在數學上表現最佳；若以對齊真實標籤的精確度（ARI）來看，$k = 11$ 表現最優。
