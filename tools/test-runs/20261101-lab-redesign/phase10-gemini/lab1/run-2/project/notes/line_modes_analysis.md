# 產線感測讀數運作模式分析報告

## 1. 概述
本分析旨在探討 `data/line_modes.csv` 中的產線感測讀數（包含溫度、震動、壓力、流量、電流、轉速等 6 個主要特徵變數）究竟包含幾種不同的運作模式（Operating Modes）。

## 2. 分析方法
資料共計 723 筆記錄。我們移除了常數欄位（`firmware_ver` 與 `sample_period_s`），並對特徵進行標準化處理（StandardScaler）。
接著使用**高斯混合模型（Gaussian Mixture Model, GMM）**與**K-Means 聚類演算法**，透過不同的分群數 $K$（從 2 到 12）進行模型評估。

評估指標包括：
- **貝氏資訊準則（Bayesian Information Criterion, BIC）**
- **輪廓係數（Silhouette Score）**
- **Calinski-Harabasz 指數**
- **Davies-Bouldin 指數**

## 3. 評估結果與分群數判定
當分群數 $K = 9$ 時，各項統計指標達到最佳狀態：
- **Silhouette Score**: $0.7943$（分群結構最為緊密且分離）
- **Calinski-Harabasz Score**: $4726.31$
- **Davies-Bouldin Index**: $0.2740$（分群重疊度最低）
- **BIC 值**: $-1064.76$（達到全域最小值附近之極佳平衡）

因此，判定該產線共有 **9 種** 不同的運作模式。
