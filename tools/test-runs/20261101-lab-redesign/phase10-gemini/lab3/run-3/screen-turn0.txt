     模型訓練與評估摘要                                                                                                 
                                                                                                                        
     - 資料特性：總樣本數 900 筆，其中故障樣本 71 筆（佔比約 $7.9\%$），屬類別不平衡資料。                              
     - 模型表現：                                                                                                       
       - Logistic Regression：ROC-AUC = 0.9781，PR-AUC = 0.8824，召回率 (Recall) 達 $93\%$。                            
       - Random Forest / Hist Gradient Boosting：ROC-AUC 分別為 0.9348 與 0.9148，精確率 (Precision) 最高達 $67\%$。    
     - 關鍵影響特徵：前三大重要特徵依序為溫度 (temp_c)、震動 (vibration_mm_s) 與 *壓力 (pressure_kpa)*。                
                                                                                                                        
     ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────  
                                                                                                                        
     能不能上線用？                                                                                                     
                                                                                                                        
     結論：可以作為「輔助預警系統」上線，但不建議直接進行「全自動停機控制」。                                           
                                                                                                                        
     - 為什麼可以上線？                                                                                                 
       模型（特別是羅吉斯迴歸）的 ROC-AUC 高達 0.978，且故障召回率達 $93\%$，能夠有效捕捉絕大多數的潛在故障，           
       降低漏報風險，避免重大設備損壞。                                                                                 
     - 上線時的注意事項（限制與建議）：                                                                                 
       1. *誤報率 (False Positives)*：模型的精確率約在 $45\% - 67\%$ 之間，代表會有一定比例的誤報。                     
          若直接連動自動停機，會造成不必要的產能損失與現場操作人員的「警報疲勞」。                                      
       2. 建議部署方式：初期建議部署為產線監控儀表板與預警通知，當模型判定高風險時，由工程師進行人工複查與預防性維護。  
       3. 後續優化：上線前可依實際業務的停機成本與維修成本比例進行*閥值調優 (Threshold Tuning)*，以達到最佳成本效益。
