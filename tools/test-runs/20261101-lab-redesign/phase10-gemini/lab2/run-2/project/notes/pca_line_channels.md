# 產線感測資料 PCA 降維分析報告

本報告針對 `data/line_channels.csv` 中的產線感測資料進行主成分分析 (Principal Component Analysis, PCA)，評估特徵維度並決定保留幾個主成分已足夠。

## 1. 資料概況與前處理

- **樣本數**：800 筆紀錄
- **特徵數**：11 個感測通道（`ch01` 至 `ch11`）
- **量級差異**：各通道的數值量級差異顯著（例如 `ch09`、`ch10` 數值在 $0.01 \sim 0.1$ 之間，而 `ch11` 則高達數十萬至百萬級）。
- **標準化**：由於 PCA 對變數尺度高度敏感，在進行主成分分析前，已使用標準化方法（StandardScaler）將所有特徵轉化為均數為 0、變異數為 1 的標準常態分佈：
  $$z = \frac{x - \mu}{\sigma}$$

---

## 2. 主成分分析結果

經過標準化與特徵值分解後，各主成分的解釋變異數比例（Explained Variance Ratio）與累積解釋變異數如下表所示：

| 主成分 (PC) | 個別解釋變異數比例 (%) | 累積解釋變異數比例 (%) |
| :---: | :---: | :---: |
| **PC1** | 31.95% | 31.95% |
| **PC2** | 20.52% | 52.47% |
| **PC3** | 16.55% | 69.02% |
| **PC4** | 14.86% | 83.88% |
| **PC5** | 9.07% | **92.95%** |
| **PC6** | 3.33% | **96.27%** |
| **PC7** | 1.56% | 97.83% |
| **PC8** | 0.84% | 98.67% |
| **PC9** | 0.65% | 99.32% |
| **PC10** | 0.47% | 99.78% |
| **PC11** | 0.22% | 100.00% |

---

## 3. 降維維度建議（看幾個主成分就夠？）

根據累積解釋變異數的標準：

1. **若以 90% 解釋變異數為目標**：
   - 需要選取 **前 5 個主成分 (PC1 ~ PC5)**，其累積解釋變異數可達到 **92.95%**，成功將 11 維度縮減至 5 維度，同時保留了超過九成的資料變異資訊。

2. **若以 80% 解釋變異數為目標**：
   - 需要選取 **前 4 個主成分 (PC1 ~ PC4)**，累積解釋變異數為 **83.88%**。

3. **若需更高精度（> 95%）**：
   - 則建議選取 **前 6 個主成分 (PC1 ~ PC6)**，累積解釋變異數達 **96.27%**。
