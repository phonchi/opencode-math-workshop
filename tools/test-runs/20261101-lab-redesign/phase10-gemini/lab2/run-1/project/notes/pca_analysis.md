# 產線感測資料 PCA 降維分析報告

本報告針對 `data/line_channels.csv` 中的 11 個產線感測器通道資料進行主成分分析（Principal Component Analysis, PCA），以評估資料的維度縮減與主成分選取數量。

## 1. 分析方法與步驟

由於各感測器通道（`ch01` 至 `ch11`）之量測尺度與數值範圍差異顯著（例如通道 11 的數值量級達百萬，而部分通道數值較小），在進行 PCA 前先進行**特徵標準化（Standardization）**，使每一通道的均值為 0、變異數為 1：

$$Z = \frac{X - \mu}{\sigma}$$

標準化後，計算共變異數矩陣之特徵值與特徵向量，並求得各主成分（Principal Component, PC）所解釋的變異數比例。

## 3. 主成分選取建議（要選幾個主成分？）

評估主成分數量的常用準則有三種：

1. **Kaiser 準則（特徵值 > 1）**：
   - 特徵值大於 1 的主成分包含 **PC1、PC2、PC3、PC4**（共 4 個），其對應的解釋變異數累積達 **83.88%**。

2. **累積變異數門檻（>= 85% 或 90%）**：
   - 若要求累積解釋變異數達到 **85%** 以上，需選取前 **5 個主成分**（PC1 ~ PC5，累積變異數達 **92.95%**，其中 PC5 的特徵值為 0.9987，非常接近 1）。
   - 若可接受 83.88%，則 **4 個主成分**已足夠。

## 4. 結論與建議

- **輕度降維（保留 >90% 資訊）**：建議選擇 **5 個主成分**（PC1 至 PC5），可保留 **92.95%** 的資料變異。
- **極致降維（保留 ~84% 資訊並滿足 Kaiser 準則）**：建議選擇 **4 個主成分**（PC1 至 PC4），可將 11 維特徵壓縮至 4 維，同時保留 **83.88%** 的變異數。
