# 產線感測資料 PCA 降維分析報告

## 1. 資料概況
- 資料來源：`data/line_channels.csv`
- 樣本數：800 筆
- 特徵數：11 個通道 (`ch01` 至 `ch11`)

## 2. 標準化與主成分分析 (PCA)
由於各通道感測器的量測尺度差異極大（例如 `ch11` 數值高達百萬，而 `ch09`、`ch10` 僅在 0.02 ~ 0.06 之間），在進行 PCA 前必須先進行標準化（$\mu = 0, \sigma = 1$）。

各主成分的特徵值（Eigenvalue）、單獨解釋變異數比例與累積解釋變異數比例：

- **PC1**: 單獨 $31.95\%$, 累積 $31.95\%$ (特徵值: 3.5190)
- **PC2**: 單獨 $20.52\%$, 累積 $52.47\%$ (特徵值: 2.2598)
- **PC3**: 單短 $16.55\%$, 累積 $69.02\%$ (特徵值: 1.8224)
- **PC4**: 單獨 $14.86\%$, 累積 $83.88\%$ (特徵值: 1.6370)
- **PC5**: 單獨 $9.07\%$, 累積 $92.95\%$ (特徵值: 0.9987)
- **PC6**: 單獨 $3.33\%$ , 累積 $96.27\%$ (特徵值: 0.3663)
- **PC7**: 單獨 $1.56\%$, 累積 $97.83\%$ (特徵值: 0.1717)
- **PC8**: 單獨 $0.84\%$, 累積 $98.67\%$ (特徵值: 0.0920)
- **PC9**: 單獨 $0.65\%$, 累積 $99.32\%$ (特徵值: 0.0717)
- **PC10**: 單獨 $0.47\%$, 累積 $99.78\%$ (特徵值: 0.0513)
- **PC11**: 單獨 $0.22\%$, 累積 $100.00\%$ (特徵值: 0.0238)

## 3. 主成分選擇建議

依據常見的降維準則：
1. **Kaiser 準則（特徵值 $> 1$）**：前 4 個主成分的特徵值均大於 1（第 5 個為 0.9987 接近 1）。
2. **累積解釋變異數門檻**：
   - 選擇 **4 個主成分**可解釋 **83.88%** 的總變異。
   - 選擇 **5 個主成分**可解釋 **92.95%** 的總變異（超過 90% 的常見工程門檻）。
   - 選擇 **6 個主成分**可解釋 **96.27%** 的總變異。

**結論**：建議保留 **5 個主成分**（可保留近 93% 的資訊量，將 11 維降至 5 維），若需更高壓縮比則保留 **4 個主成分**（約 84% 資訊量）。相關圖表已儲存至 `figs/pca_variance.png`。
