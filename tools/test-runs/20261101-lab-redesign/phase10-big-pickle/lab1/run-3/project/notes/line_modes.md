# 產線感測資料的運作模式數

資料：`data/line_modes.csv`，723 筆樣本、6 個有效感測變數（溫度、振動、壓力、流量、電流、轉速）。
`firmware_ver` 固定為 3.0、`sample_period_s` 固定為 0.5，對分群沒有資訊。

## 結論

資料可分成 **9 種運作模式**。

## 判別依據

先將 6 個感測變數標準化，再比較不同分群數：

| 指標 | 結果 |
|---|---|
| GMM BIC（full covariance） | \(k=9\) 最小（-1064.8），\(k=10\) 後回升 |
| K-means silhouette | \(k=9\) 最高（0.794） |
| Calinski–Harabasz | \(k=9\) 最高（4726） |
| Davies–Bouldin | \(k=9\) 最低（0.274） |
| 穩定性 | 6 個不同隨機種子的 K-means 分群完全一致（ARI = 1.0） |
| GMM 與 K-means | 9 群的指派完全一致（ARI = 1.0），且 GMM 最大後驗機率皆為 1.0 |

各群內標準差遠小於整體標準差（例如溫度約 1.3 °C vs 11.2 °C），代表 9 群各自緊密、彼此分離，不是硬切出來的。
