# 產線感測資料 PCA 降維

- 資料：`data/line_channels.csv`，800 筆樣本、11 個通道，無缺值。
- 各通道單位與尺度差異大（ch11 約 $10^6$、ch09 約 $10^{-2}$），因此先對每個通道做 z-score 標準化，再對相關係數矩陣做 PCA。

## 要保留幾個主成分

| 判準 | 建議個數 |
|---|---|
| Kaiser（特徵值 > 1） | 4 |
| Parallel analysis（95%） | 4 |
| 累積解釋變異 >= 80% | 4 |
| 累積解釋變異 >= 90% | 5 |

**建議保留 4 個主成分**（PC1–PC4），累積解釋約 83.9%。

結構解讀：PC1–PC3 主要由 ch01–ch08 這組互相關聯的通道構成；PC4 幾乎就是 ch09 與 ch10 的共同變化；PC5 則幾乎單獨對應 ch11（負荷量約 -1.00）。
因此四個判準都指向 4 個 PC，但這會把變異最大的 ch11 完全排除。若後續要做異常偵測、且 ch11 是重要感測訊號，建議保留 5 個 PC（累積解釋 93.0%），以保留 ch11 的獨立資訊。
