# 產線感測資料 PCA 降維

資料：`data/line_channels.csv`，800 筆樣本、11 個通道（`ch01`–`ch11`），無缺失值。
分析腳本：`pca_line_channels.py`。

## 方法

每個通道尺度差異極大（例如 `ch11` 的標準差約 $3.0\times10^5$，`ch02` 只有 $0.32$），
因此先做標準化：

$$
z_{ij}=\frac{x_{ij}-\bar{x}_j}{s_j},
$$

再對相關係數矩陣做 PCA。主成分為

$$
\mathbf{z}_i \approx \sum_{k=1}^{K} t_{ik}\,\mathbf{v}_k,
$$

其中 $\mathbf{v}_k$ 為第 $k$ 個主成分的負荷量（loading），$t_{ik}$ 為得分（score）。

## 結果

| 主成分數 $K$ | 累積解釋變異 | 說明 |
|---:|---:|---|
| 1 | 31.95% | |
| 2 | 52.47% | |
| 3 | 69.02% | |
| 4 | 83.88% | Kaiser 準則（特徵值 $>1$）建議 4 個 |
| 5 | 92.95% | 超過 90% |
| 6 | 96.27% | 超過 95% |

特徵值為 $3.51, 2.26, 1.82, 1.64, 1.00, 0.37, \ldots$，只有前 4 個大於 1。

![陡坡圖與累積解釋變異](../figs/pca_scree.png)

## 但「平均解釋變異」會誤導

負荷量矩陣顯示，前 3 個主成分幾乎只由 `ch01`–`ch08` 組成，
`ch09`、`ch10`、`ch11` 的負荷量都接近 0：

![主成分負荷量](../figs/pca_loadings.png)

逐通道的重建 $R^2$ 更清楚：

![各通道重建 R²](../figs/pca_reconstruction.png)

- $K=3$：`ch01`–`ch08` 的 $R^2$ 約 0.89–0.97，但 `ch09`、`ch10`、`ch11` 幾乎為 0。
- $K=4$：`ch09`、`ch10` 提升到約 0.82，`ch11` 仍為 0。
- $K=5$：`ch11` 才被重建（$R^2\approx1$）。
- $K=6$：11 個通道全部可重建。

原因是這 11 個通道不是同一個低維結構，而是三個區塊：

| 區塊 | 有效維度 | 累積解釋變異 |
|---|---:|---:|
| `ch01`–`ch08` | 3 | 94.86% |
| `ch09`–`ch10` | 2 | 100%（兩者相關 $0.63$） |
| `ch11` | 1 | 獨立通道 |

## 建議

- 若只關心機台核心狀態（`ch01`–`ch08`）：**3 個主成分就夠**，已解釋這 8 個通道 94.9% 的變異。
- 若 11 個通道都要保留：**需要 6 個主成分**（96.3%），因為 `ch09`、`ch10`、`ch11` 幾乎與前 8 個通道獨立，無法靠共同變異壓縮。
- 若可以放棄 `ch11`：4 個主成分（83.9%）即可；此時 `ch09`、`ch10` 只保留共同模式（$R^2\approx0.82$）。
- 不建議直接採用「5 個主成分、92.9%」這種只看總變異的做法：它雖然救回 `ch11`，但 `ch09`、`ch10` 的差異維度仍只重建到 $R^2\approx0.82$。比較穩健的做法是對 `ch01`–`ch08` 取 3 個主成分，並將 `ch09`、`ch10`、`ch11` 單獨保留。
