     判斷兩個模型一樣，依序看：                                                                                         
                                                                                                                        
     1. 先確認資料切分、標籤、前處理、截距、損失、正則化強度都相同（sklearn 的 C 要換成 λ = 1/(nC)）。                  
     2. 比預測而非係數：max|Δz|、max|Δp|、預測標籤不同筆數；例如 max|Δp|<1e-6 且 0 筆不同。                             
     3. 比最佳化條件：梯度範數接近 0、目標函數值在浮點誤差內。                                                          
     4. 係數只在模型可辨識且參數化相同時比較；若要比泛化表現，另用 bootstrap 信賴區間、McNemar、DeLong 等統計檢定。     
        「準確率一樣」不等於模型一樣。
