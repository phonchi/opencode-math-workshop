                                                                                                                        
     ## 步驟                                                                                                            
     1. 中心化：$X_c = X - \bar{x}$                                                                                     
     2. 共變異數矩陣：$S = \frac{1}{n-1}X_c^T X_c$                                                                      
     3. 特徵分解：$S v_i = \lambda_i v_i$，取 $\lambda$ 最大對應之 $v_i$ 組成 $V_k = [v_1,\ldots,v_k]$                  
     4. 投影：$Z = X_c V_k$                                                                                             
                                                                                                                        
     ## 驗證方式                                                                                                        
     - 比對 `explained_variance_ratio_`：$\lambda_i / \sum_j \lambda_j$                                                 
     - 投影值可能差正負號，改用逐欄 $|\mathrm{corr}(Z_{:,j}^{(scratch)}, Z_{:,j}^{(sklearn)})| \approx 1$               
     - 主成分向量只需方向一致，改用 $|v^{(scratch)}| \approx |v^{(sklearn)}|$                                           
                                                                                                                        
     ## 結論                                                                                                            
     只要共變異數矩陣正確、$eigh$ 排序正確且考慮正負號，手刻結果就會與 `sklearn.PCA` 高度吻合。
