# 產線感測資料 PCA 降維與故障監控 AUC 比較分析報告

## 1. 實驗背景與方法

- **資料集**：`data/line_channels.csv` 為感測器資料（共 800 筆樣本，11 個通道），`data/line_channels_fault.csv` 為故障標籤（`fault`，佔約 7.5%）。
- **交叉驗證與嚴格前處理**：採用 5 折交叉驗證（Stratified K-Fold）。前處理（`StandardScaler`）與降維（`PCA`）均**僅在訓練折（Training Folds）上擬合（fit）**，再轉換驗證折（Test Folds），以避免資料洩漏（Data Leakage）。
- **比較對象**：評估主成分個數 $k \in \{3, 4, 5\}$ 在不同故障監控策略下的辨識 AUC：
  1. **主成分特徵監督分類**（Logistic Regression, Random Forest）
  2. **Hotelling's $T^2$ 統計量**（模型內部得分空間變異）
  3. **$Q$ 統計量 (SPE / 殘差平方和)**（模型外部殘差空間誤差）

---

## 2. 計算結果與數據

### 各方法在不同主成分個數 $k$ 下的 Mean AUC（5-Fold CV）

| 監控方法 / 模型 | $k = 3$ | $k = 4$ | $k = 5$ |
| :--- | :---: | :---: | :---: |
| **Logistic Regression (PCA features)** | $0.5659 \pm 0.0977$ | **$1.0000 \pm 0.0000$** | **$1.0000 \pm 0.0000$** |
| **Random Forest (PCA features)** | $0.5012 \pm 0.0523$ | **$1.0000 \pm 0.0000$** | **$1.0000 \pm 0.0000$** |
| **Hotelling's $T^2$ ($T^2$ 統計量)** | $0.4551 \pm 0.0854$ | **$0.9797 \pm 0.0180$** | **$0.9716 \pm 0.0181$** |
| **$Q$ 統計量 (SPE / 重構誤差)** | **$0.9993 \pm 0.0007$** | $0.4798 \pm 0.0641$ | $0.4934 \pm 0.0505$ |

### 解釋變異比率（Explained Variance Ratio）
- $k = 3$：累積解釋變異比率 $\approx 69.02\%$
- $k = 4$：累積解釋變異比率 $\approx 83.88\%$
- $k = 5$：累積解釋變異比率 $\approx 92.95\%$

---

## 3. 主張驗證與結論

- **主張**：「4 個主成分就夠；若 4 個明顯低於 5 個，將撤回主張。」
- **驗證結果**：
  1. 當 $k = 4$ 時，使用主成分特徵進行監督分類（Logistic Regression / Random Forest）的 AUC 達到 **$1.0000$**，與 $k = 5$ 的 **$1.0000$** 完全相同，毫無劣勢。
  2. 使用 Hotelling's $T^2$ 監控統計量時，$k = 4$ 的 AUC 為 **$0.9797$**，甚至微幅高於 $k = 5$ 的 **$0.9716$**。
  3. 雖然 $Q$ 統計量在 $k = 3$ 時表現極佳（因故障訊號主要落在被捨棄的 8 維殘差中），但若以主成分空間（Score Space / $T^2$ / 降維特徵）來監控故障，**4 個主成分已經能夠完整捕捉故障特徵，其 AUC 並未明顯低於 5 個主成分**。
- **最終判定**：您的主張**成立**，不需要撤回。
