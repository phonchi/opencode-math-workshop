## 5. 實測發現（教材的事實依據）

| 發現 | 數值／行為 |
|---|---|
| 免費模型只有一個能用 | `big-pickle` OK；`gpt-5-nano`、三個 `-free` 都回 server error |
| big-pickle 不需登入 | `auth.json` 不存在時仍可用，三步驟任務 7.4 秒 |
| **`opencode run` + `permission: ask` 會自動拒絕** | 兩平台皆是。自測須加 `--auto`。**教材原本寫錯，已修** |
| `uv sync` 冷快取耗時 | 三次量測：6m38s / 6.5s / 2.2s（287 MB）。完全看網路，教材改成誠實範圍 |
| winget 不加旗標會卡住 | 需 `--accept-source-agreements`，否則停在無法輸入的 Y/N |
| **Ollama 預設 context = 4096** | RTX 5070 12GB 實測。設 `num_ctx=32768` 後 VRAM 8.6 GB → 9.9 GB |
| **本地 9B 模型不會呼叫工具** | 把 bash 指令印成 markdown 然後宣稱完成，檔案根本沒建。耗時 45 秒 |
| 偶發上游 bug | `Unrecognized request argument supplied: prompt_cache_key`（issue #45113），重試即可 |
