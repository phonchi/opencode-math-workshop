工作坊課程島

OpenCode × AI-Math · NSYSU

課程島載入中…

拖曳旋轉 · 滾輪或雙指縮放 · 點地標

15 個單元，全部可以自由進入。現場兩小時走主島的步道；課後的三條路線各是一座小島。 「足跡」只存在這台裝置的瀏覽器裡。

啟航港開始之前

總覽與課前準備。出發前先把三樣工具裝好、看到綠燈。

  1. 00 工作坊總覽 瞭望台 用 OpenCode 跑實驗、畫圖、整理筆記，並用數學驗證 agent 的答案。
  2. 01 課前準備 綠燈檢修棚 安裝 OpenCode 與 uv，準備工作坊專案並完成自測。

現場步道現場兩小時

第一次對話，再走三個 Lab。步道旁的時刻牌是現場的時間表。

  1. 02 第一次對話 權限柵欄 啟動 OpenCode、下達任務、檢查工具執行，認識權限與 session。 需要時可查閱：速查表
  2. L1 Lab 1 · 分群 手搖飲攤車廣場 讓 agent 跑分群實驗，先講清楚用途，再判斷該分幾群。 需要時可查閱：第一次對話、速查表
  3. L2 Lab 2 · PCA 外送投影台 依用途判斷幾個主成分才夠，再實作 PCA，看驗證能不能抓到錯誤。 需要時可查閱：第一次對話、速查表
  4. L3 Lab 3 · 分類與筆記 圖書館門檻尺 訓練分類模型，由你依代價拍板門檻，再把決定與限制整理成筆記。 需要時可查閱：第一次對話、速查表

工坊島課後 · OpenCode 操作

六間工坊，把 OpenCode 用得更順手；最外面的 Herdr 是選修。

  1. C1 讓 agent 把工作做完整 交接驛站 把需求拆成可執行的任務，檢查結果並保存可以接續的成果。
  2. C2 AGENTS.md 專案規則 入口告示牌 把專案規則寫成 AGENTS.md，讓 agent 知道工作方式與驗證要求。
  3. C3 git 安全網 安全網跳台 動手前存檔、改完看 diff，學會保留與還原修改。
  4. C4 MCP、skills 與 subagent 工具坊 認識工具擴充、工作流程與子任務，選擇合適的協作方式。
  5. C5 本地模型 自家機房 估算電腦放得下哪些模型，以 Ollama 連接 OpenCode，設好 context 與安全設定。
  6. C6 用 Herdr 讓 OpenCode 找幫手 雙塔觀測站 讓 OpenCode 自己開另一個 OpenCode 當 reviewer，交代工作、收回報，你在側欄看得到每一步。

數學島課後 · 數學應用

低秩近似、梯度下降與最短路徑，先寫下怎樣算完成，交給 agent 算和畫，再自己判讀。

  1. M1 數學應用練習 三題涼亭 從低秩近似、梯度下降與最短路徑出發，練習用 agent 協助探索與驗證。

筆記島課後 · 閱讀與筆記

整理指定的數學來源，每一句都分清楚是原文、AI 解釋還是自己推的。

  1. R1 整理數學文獻與筆記 核對桌 用 OpenCode 整理指定的數學來源，回到原文與自己的 Lab 核對，留下一份可追溯的閱讀筆記。

速查燈船隨時查閱

停在港心，任何時候都點得到。

  1. Q 速查表 速查燈船 查找常用操作、指令與排錯方法。
