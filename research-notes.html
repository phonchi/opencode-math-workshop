課後補充：整理數學文獻與筆記

做完 Lab 之後，你可能還想問：「PCA 為什麼要先減掉平均？」這一章就從這個問題出發，沿用 OpenCode，把一小段公開資料和自己的程式整理成一頁可複習的筆記。遇到課本、講義或論文，也可以用同樣的方式從一個問題開始讀。

先帶著一個問題閱讀

這次只問：PCA 的中心化做了什麼？和把每個特徵縮放到相同尺度有什麼不同？

先在瀏覽器開啟 scikit-learn 的 PCA 說明，讀「2.5.1.1. Exact PCA and probabilistic interpretation」開頭介紹 PCA 與中心化的短段落即可。暫時不用讀機率模型、增量演算法或後面的其他方法。

在工作坊的 ai-math-lab 專案裡，用文字編輯器建立 notes/pca-source.txt。貼上你選的短片段，並在前面記下網址、節名和閱讀日期。這次用公開網頁就能練習，不需要下載整篇文件或安裝新工具；請勿提供未公開或無權上傳的材料。

把來源交給 OpenCode

回到這個專案的 OpenCode 對話，用 @notes/pca-source.txt 指定剛才的檔案。若已完成 Lab 2，也讓它讀 lab2_pca.py；自己的執行結果若已存成檔案或筆記，再補上實際路徑。只有程式、沒有結果也能做這一題，缺少的觀察留待補上。

下面的任務可以直接複製。檔案若還沒準備好，先完成上一節再送出。

請讀 AGENTS.md 和 @notes/pca-source.txt。
我要整理「PCA 的中心化做了什麼？和特徵縮放有什麼不同？」。
若 lab2_pca.py 存在，請讀取；也先查看 notes/ 中有哪些相關筆記，
只讀與這題有關的內容，不要猜不存在的輸出路徑。

請根據指定片段整理定義、必要假設和主要結論，再補一段簡短解釋。
需要推導或小例子時，先定義符號，逐步寫出；
若有反例可幫助理解，可以提供，但不要冒稱是原文的例子。
每項論斷用 [原文]、[AI 解釋] 或 [我推導] 其中一個標記。
[我推導] 只留給我實際提供或自己完成的內容，不要代填。
原文沒提的假設、理由或推導，不能歸到 [原文]。

指出 lab2_pca.py 中對應中心化的程式碼，以及我可以自己檢查的一步。
程式不存在就跳過這項，標明尚未提供。
沒有實際執行輸出時，標明結果待補，不為了寫筆記重跑實驗。
列出還不能從指定片段回答的問題，存成 notes/pca-reading.md。
若該筆記已存在，先讀內容並保留我寫過的推導，再更新。
讀不到來源檔就停下來告訴我缺什麼，不要猜測原文或另找資料代替。

回原文，再回自己的 Lab

打開筆記，把標成 [原文] 的句子逐一對回摘錄。例如，文件說 PCA 會中心化輸入，但不會預先縮放每個特徵。若筆記把它寫成「PCA 會自動標準化到單位變異數」，就需要修正。原文說明了程式的行為，未必完整回答它的數學理由；這一段理由應另外核對。

接著看自己的 lab2_pca.py。減掉的平均是沿哪個軸算的？每個特徵減去各自平均後，欄平均應接近零。程式寫了這一步，和你已經看過執行結果，是兩件事；筆記要照目前手上的證據寫。

也可以先手算一個小例子：同一個特徵的三筆值是 $2,4,6$，平均是 $4$，中心化後得到 $-2,0,2$。平均變成零，但數值沒有因此縮放到單位變異數。你算過並確認的步驟，才標成 [我推導]；agent 提供的解釋仍標成 [AI 解釋]。

讀不到原文時，把你能閱讀的短摘錄存進來源檔再繼續。若仍無法判斷某句是否有根據，就在筆記寫「待查」，不用急著補成完整答案。

留下一頁下次看得懂的筆記

這份模板由本工作坊設計。每個要點選一個適合的標記；不用每行都塞入三種。範本中的提示填完就刪掉，沒有證據的欄位可以寫「待補」。

# PCA 閱讀筆記

問題：PCA 的中心化做了什麼？和特徵縮放有什麼不同？

## 來源
- 網址：https://scikit-learn.org/stable/modules/decomposition.html#pca
- 節名：2.5.1.1. Exact PCA and probabilistic interpretation
- 閱讀日期：填入實際日期
- 摘錄：notes/pca-source.txt
- 其他來源如有使用，附頁碼、式號或可定位的段落；沒有則省略。

## 定義、假設與重點
- [原文] 用自己的話記下一個重點，附對應節名或摘錄段落。
- [AI 解釋] 記下幫助理解的說明，以及仍需核對的假設。

## 我能核對的一步
- [我推導] 寫下自己算過的小例子或推導，先定義符號。
- Lab 對照：填入實際程式路徑與相關步驟。
- 執行結果：附實際結果檔路徑；未提供就寫「待補」。

## 還沒弄懂
- 寫下一個來源沒有回答，或自己還不能說清楚的問題。

## AI 使用紀錄
- 工具與日期：OpenCode；填入實際日期。
- 用途：整理指定摘錄、解釋概念、協助對照程式。
- 自己核對或修正：記下實際完成的部分。

收好筆記前，先關掉 agent 的解釋，用自己的話回答開頭的問題。說不清楚的地方，就留作下次閱讀的起點。若已建立 math-notes skill，也可以把這次有用的整理方式加入流程。

選讀：讀第二篇資料時怎麼比較

先沿用同一個問題，再選另一份你能合法閱讀的講義或文章。把短摘錄和出處另存一份來源檔，要求 agent 逐項比較「符號怎麼定義、假設是什麼、回答了問題的哪一部分」。

例如，兩份資料的共變異數分母分別是 $n$ 和 $n-1$，先確認 $n$ 都指樣本數，再推導這個差異會改變哪些量。摘錄沒有說明原因，就標成待查；不要把兩段說法硬湊成一致。需要查參數定義時，可另讀 PCA API 文件 的相關項目。

延伸來源

本章參考成大 AI 素養資源中「先定問題、整理指定來源、由人回原文核對、留下閱讀與 AI 使用紀錄」的流程，改編成 OpenCode 的數學閱讀練習。上面的 PCA 任務與筆記模板為本工作坊設計。
